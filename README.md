# ElectroHogar

Proyecto educativo de una tienda online ficticia de electrodomésticos, desarrollado como pre-entrega del curso de Desarrollo Web.

## Objetivo
Practicar la estructura semántica de HTML, los estilos con CSS, la distribución de elementos con Flexbox y Grid, el diseño responsivo y la creación de un formulario de contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree para el formulario de contacto

## Secciones del sitio
- Inicio
- Productos
- Nosotros
- Reseñas
- Contacto

## Estructura
- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos y diseño responsivo.
- `img/`: carpeta reservada para imágenes locales si se desea agregarlas.

## Antes de entregar
1. Crear una cuenta en Formspree y generar un formulario.
2. Reemplazar `TU_ID` en el atributo `action` del formulario de `index.html` por el identificador real de Formspree.
3. Probar el envío del formulario.
4. Publicar el repositorio en GitHub Pages.

## Publicar en GitHub Pages
1. Crear un repositorio público en GitHub.
2. Subir `index.html`, `styles.css`, `README.md` y cualquier otro recurso.
3. Abrir Settings > Pages.
4. En Build and deployment, seleccionar `Deploy from a branch`.
5. Elegir la rama `main` y la carpeta `/ (root)`.
6. Guardar y esperar a que GitHub Pages publique el sitio.
